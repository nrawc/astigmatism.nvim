## astigmatism.nvim

A dark Neovim color scheme for people with astigmatism. Astigmatism can cause high contrast or highly saturated text to appear to glow or blur even with glasses. This color scheme attempts to fix that.

### Installation

Just add this to your lazy setup.

```lua
"nrawc/astigmatism.nvim"
```

Then add this to your init.lua to enable the colorscheme.

```lua
vim.cmd.colorscheme('astigmatism')
```

### Note from the author
I am not a doctor, just a programmer with astigmatism who made this plugin for himself. I personally can read code much better now. If it helps anyone else, cool.
